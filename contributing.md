# Contribution guidelines

Pull requests are welcome. To keep the list useful:

- One pull request per suggestion.
- The project must help old games run on modern displays: resolution, aspect ratio, HUD scaling, windowing, or a
  graphics API that no longer works properly.
- Link the project's own page (repository or official site), not a mirror or a reupload.
- Use the format `[Name](link) - Description.`: the description starts with a capital letter and ends with a
  period.
- Put the entry in the right section. In «Per-game mods», keep entries sorted by game name.
- Check spelling and grammar, and remove trailing whitespace.

By contributing, you agree that your contribution is released under [CC0 1.0](LICENSE).
